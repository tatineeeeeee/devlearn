# Responsive Design Patterns with Tailwind CSS

Learn how to build beautiful, responsive layouts using Tailwind CSS's mobile-first approach and powerful utility classes.

## Understanding Breakpoints

Tailwind uses a mobile-first approach with these default breakpoints:

| Breakpoint | Min Width | CSS                          |
| ---------- | --------- | ---------------------------- |
| `sm`       | 640px     | `@media (min-width: 640px)`  |
| `md`       | 768px     | `@media (min-width: 768px)`  |
| `lg`       | 1024px    | `@media (min-width: 1024px)` |
| `xl`       | 1280px    | `@media (min-width: 1280px)` |
| `2xl`      | 1536px    | `@media (min-width: 1536px)` |

## Mobile-First Approach

Start with mobile styles, then add larger screen overrides:

```html
<!-- Mobile: single column, Tablet: 2 columns, Desktop: 3 columns -->
<div class="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
  <div class="p-4 bg-white rounded-lg shadow">Card 1</div>
  <div class="p-4 bg-white rounded-lg shadow">Card 2</div>
  <div class="p-4 bg-white rounded-lg shadow">Card 3</div>
</div>
```

## Responsive Card Grid

```tsx
export function ProductGrid() {
  const products = [
    { id: 1, name: "Product 1", price: 99, image: "/product1.jpg" },
    { id: 2, name: "Product 2", price: 149, image: "/product2.jpg" },
    { id: 3, name: "Product 3", price: 199, image: "/product3.jpg" },
    { id: 4, name: "Product 4", price: 79, image: "/product4.jpg" },
  ];

  return (
    <div className="max-w-7xl mx-auto px-4 sm:px-6 lg:px-8 py-12">
      <h2 className="text-2xl sm:text-3xl font-bold mb-8">Our Products</h2>

      {/* Responsive grid: 1 col → 2 cols → 3 cols → 4 cols */}
      <div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4 gap-4 sm:gap-6">
        {products.map((product) => (
          <div
            key={product.id}
            className="bg-white rounded-xl shadow-sm hover:shadow-md transition overflow-hidden"
          >
            {/* Responsive aspect ratio */}
            <div className="aspect-square sm:aspect-[4/3] bg-gray-100">
              <img
                src={product.image}
                alt={product.name}
                className="w-full h-full object-cover"
              />
            </div>

            {/* Responsive padding */}
            <div className="p-4 sm:p-5">
              <h3 className="font-semibold text-gray-900">{product.name}</h3>
              <p className="mt-1 text-lg font-bold text-blue-600">
                ${product.price}
              </p>

              <button className="mt-4 w-full py-2 bg-blue-600 text-white rounded-lg hover:bg-blue-700 transition">
                Add to Cart
              </button>
            </div>
          </div>
        ))}
      </div>
    </div>
  );
}
```

## Container Queries (Tailwind v4)

Container queries let you style based on parent size:

```tsx
export function ResponsiveCard() {
  return (
    <div className="@container">
      <div className="flex flex-col @md:flex-row gap-4 p-4 bg-white rounded-lg shadow">
        {/* Image: full width on small containers, fixed width on larger */}
        <div className="w-full @md:w-48 aspect-video @md:aspect-square bg-gray-200 rounded-lg" />

        {/* Content adapts to container size */}
        <div className="flex-1">
          <h3 className="text-lg @lg:text-xl font-semibold">Card Title</h3>
          <p className="mt-2 text-gray-600 text-sm @lg:text-base">
            This card adapts based on its container width, not the viewport.
          </p>
        </div>
      </div>
    </div>
  );
}
```

## Hiding/Showing Elements

Control visibility at different breakpoints:

```tsx
<div>
  {/* Only on mobile */}
  <div className="block sm:hidden">Mobile only</div>

  {/* Hidden on mobile, visible on tablet+ */}
  <div className="hidden sm:block">Tablet and larger</div>

  {/* Only on tablet */}
  <div className="hidden sm:block lg:hidden">Tablet only</div>

  {/* Desktop only */}
  <div className="hidden lg:block">Desktop only</div>
</div>
```

## Best Practices

1. **Start mobile-first** - Write base styles for mobile, add breakpoint overrides
2. **Use semantic breakpoints** - Choose breakpoints based on content, not devices
3. **Test on real devices** - Emulators don't catch everything
4. **Consider touch targets** - Minimum 44x44px for touch interactions
5. **Optimize images** - Use responsive images with srcset

## Summary

| Pattern            | Classes                                     |
| ------------------ | ------------------------------------------- |
| Hide on mobile     | `hidden sm:block`                           |
| Stack → Row        | `flex flex-col sm:flex-row`                 |
| Responsive grid    | `grid-cols-1 md:grid-cols-2 lg:grid-cols-3` |
| Responsive text    | `text-sm md:text-base lg:text-lg`           |
| Responsive spacing | `p-4 sm:p-6 lg:p-8`                         |

Master these patterns to build responsive designs efficiently!
